# Abnahmekriterien

- [ ] App startet ohne Netzwerk und zeigt Offline-Shell.
- [ ] Lokales Modell antwortet ohne Cloud.
- [ ] Alle logischen CPU-Kerne werden erkannt; Last wird bei thermischem Limit reduziert.
- [ ] Tägliche Fragen sind überspringbar und widerrufbar.
- [ ] Lernprofil ist verschlüsselt, versioniert und löschbar.
- [ ] Webgateway sendet nur nach Einwilligung anonymisierte Anfragen.
- [ ] Sprache fällt sicher auf Text zurück.
- [ ] Kiosk-Admin-PIN erlaubt WLAN-Wechsel.
- [ ] Wiederherstellung aus Backup wurde auf dem Zieltablet getestet.
