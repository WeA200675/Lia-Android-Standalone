# Tablet-Übergabe

## APK installieren

1. In GitHub Actions das Artefakt `lia-debug-apk` des grünen Builds herunterladen.
2. APK auf das Samsung-Tablet übertragen.
3. Nur für diese Installation „Unbekannte Apps installieren“ für den verwendeten Dateimanager erlauben.
4. APK installieren und die Berechtigung anschließend wieder deaktivieren.

## Erststart

- Datum/Uhrzeit automatisch
- aktuelles Android-Sicherheitsupdate
- Displaysperre mit PIN
- Mikrofonberechtigung nur bei gewünschter Sprache aktivieren
- zunächst Offline-Modus verwenden
- Admin-PIN im geschützten Admin-Bereich setzen

## WLAN und Kiosk

Das endgültige WLAN vor dem Kiosk-Modus verbinden und testen. Für einen späteren Wechsel in Lia den Bereich „Wartung / WLAN“ öffnen, Admin-PIN eingeben, WLAN ändern und danach Kiosk erneut aktivieren.

## Abnahme

- App startet ohne WLAN
- Smalltalk und Offline-Wissensimpuls funktionieren
- Tagesfrage kann beantwortet oder übersprungen werden
- Antwort erscheint nicht als unbestätigte Erinnerung
- Admin-PIN schützt WLAN-Einstellungen
- Internetmodus zeigt den aktuellen Zustand
- Lernprofil lässt sich vollständig löschen
- Mikrofon/TTS können ausfallen, ohne Textbetrieb zu verlieren
