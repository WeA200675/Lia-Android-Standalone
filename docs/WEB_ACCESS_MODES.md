# Webzugriff ohne unnötige Rückfragen

Lia unterstützt drei Modi:

- `OFFLINE`: kein Netzwerk.
- `AUTO_ANONYMIZED_GENERIC`: allgemeine Wissens- und Sachfragen werden automatisch lokal redigiert und anonymisiert gesendet.
- `ASK_BEFORE_PERSONAL`: bei möglichen persönlichen oder sensiblen Inhalten erscheint zuerst eine sichtbare Bestätigung.

Erkannte sensible Kategorien (Gesundheit, Familie, Adressen, Termine, Finanzen, Passwörter) werden nicht stillschweigend übertragen. Die Nutzerin kann den Internetmodus jederzeit deaktivieren.
