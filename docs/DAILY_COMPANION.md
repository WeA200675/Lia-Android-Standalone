# Tägliche Begleitung

Lia stellt höchstens einmal pro Kalendertag eine kurze, überspringbare Frage. Die Antwort wird lokal verschlüsselt gespeichert und erst nach Bestätigung als persönliche Erinnerung verwendet.

Der Internet-Schalter ist standardmäßig aus. Die Einwilligung wird lokal gespeichert, kann im Admin-Bereich widerrufen werden und wird bei Profil-Löschung ebenfalls entfernt.
