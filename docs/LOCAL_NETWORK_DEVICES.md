# Geräte im eigenen WLAN

Lia arbeitet nur mit ausdrücklich gepaarten Geräten. Ein konkreter Adapter (z. B. für einen Rasenroboter) muss das Herstellerprotokoll unterstützen. Lia speichert Konfigurationen verschlüsselt und stellt sie nur für dieselbe Geräte-ID wieder her. Firmware-Updates, sicherheitskritische Befehle und unbekannte Geräte bleiben gesperrt.
