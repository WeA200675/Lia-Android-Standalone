# Geräteprofil

Lia ermittelt zur Laufzeit echten Android-RAM, verfügbare logische CPU-Kerne, freien internen Speicher und den Status eines externen Speichers. RAM Plus wird nicht als echter RAM bewertet.

Modellstufen:

- 8 GB RAM und ausreichend interner Speicher: 3B-Q4
- 6–8 GB oder weniger Speicher: 2B-Q4
- geringere Ressourcen: 1.5B-Recovery

microSD ist für Backups und Recovery vorgesehen; das aktive Modell bleibt möglichst im internen Speicher.
