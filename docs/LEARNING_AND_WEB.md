# Lernen und Internet

Lia trainiert keine neuronalen Gewichte auf dem Tablet. Sie lernt den Alltag über ein verschlüsseltes, versioniertes Profil. Nur bestätigte Einträge werden in begrenztem Umfang in den Modellkontext übernommen.

Internet ist standardmäßig ausgeschaltet. Nach ausdrücklicher Freigabe wird die Eingabe lokal redigiert (E-Mail-Adressen und fünfstellige Postleitzahlen) und auf 2.000 Zeichen begrenzt. Es werden keine persönlichen Antworten, Profile oder Audiodateien automatisch ins Internet übertragen.

Webinhalte werden als unbestätigte Informationen behandelt und nicht automatisch zu dauerhaften Erinnerungen.
